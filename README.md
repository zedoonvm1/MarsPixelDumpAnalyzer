# MarsPixelDumpAnalyzer

MarsPixelDumpAnalyzer is a Windows RAM-dump scanner designed for game cheat detection and PC checking.

It helps PC checkers quickly find suspicious evidence left in memory by cheats, loaders, scripts, and other execution activity.

## Usage

1. Create a RAM dump of the PC being checked.
2. Open MarsPixelDumpAnalyzer.
3. Select the dump.
4. Start the scan.
5. Review the detected strings.

Results are intended for **manual investigation**. A detection alone is not definitive proof of cheating and should always be reviewed in context.

## Privacy

RAM dumps may contain sensitive information. Only analyze systems you are authorized to inspect, and do not publicly upload memory dumps.

## Disclaimer

MarsPixelDumpAnalyzer is an investigative aid for authorized PC checking. False positives and missed detections are possible.
